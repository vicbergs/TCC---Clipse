# Clipse: protótipo do site

Protótipo navegável da Clipse, uma plataforma de fitness natural com piloto em Curitiba.
Projeto de TCC de Design na PUCPR (2026), de Victor Bergmann.

## O que tem aqui

- `index.html`: a página
- `css/site.css`: o visual
- `js/data.js`: todo o conteúdo (fases, aulas, planos, profissionais, locais, grupos, histórias, perguntas, produtos de exemplo)
- `js/app.js`: a lógica (rotas, login simulado, Minha jornada, painel da vitrine, gestos)

Não tem dependência nem etapa de build. É HTML, CSS e JavaScript puros.

## Como ver

Abra o `index.html` no navegador, ou publique a pasta com o GitHub Pages.

## Como os dados funcionam

- O login é simulado. A jornada (fase, check-in, diário, objetivos, rede) fica salva só no navegador de quem usa.
- A vitrine de produtos roda em modo local: o que for adicionado pelo painel fica salvo só naquele navegador.

## Avisos

- Perfis, parceiros, histórias e valores são ilustrativos.
- O conteúdo é informativo e não substitui o acompanhamento de médico, nutricionista, psicólogo ou profissional de educação física.
